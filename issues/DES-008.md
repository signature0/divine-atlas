## Description
not-found.tsx is a polished generic dark-editorial 404: good type and micro-copy, but zero in-world cues of the approved concept (no tablet motif, no Duat tone, generic star glyph), 'Version 1:' breaks the mythic voice, and the composition is top-heavy with ~300px dead black below the floating footer.

## Acceptance Criteria
- [ ] Copy names the loss in underworld terms (in-world, no dev artifacts)
- [ ] One or two in-world visual cues (tablet/inscription motif or ankh/djed mark; ochre glow undertone)
- [ ] Footer grounded to bottom with hairline rule; text >= AA

## Implementation Reference
Rewrite copy, swap brand star for a culture-neutral/ankh mark on this page, ground footer, drop 'Version 1:'.
