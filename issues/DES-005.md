## Description
33 contrast failures logged (TASK-011-contrast-fails.json): Japanese vermilion rgb(192,57,43) on card surfaces at 10.9-11.5px = 3.28-3.61:1 (needs 4.5); Norse copper and Egyptian teal 3.77-4.18; --ink-2 at 4.03-4.44 on small text. DESIGN-SYSTEM claims AA contrast; it does not hold for accent-on-surface labels.

## Acceptance Criteria
- [ ] All accent-colored text >= 4.5:1 (or 3:1 if large/bold per WCAG)
- [ ] Contrast re-audit clean across home + 6 culture landings + vault
- [ ] tokens.css documents the per-culture accent-text split

## Implementation Reference
Brand: define --accent-text (lightened >=4.5:1) for text uses; keep --accent for rules/badges (non-text). Bump --ink-2 one step for small text or restrict it to >=14px.

## QA Notes
Fix applied (Brand, 2026-09-14): per-culture `--accent-text` / `--accent-2-text` tokens added to globals.css + data/cultures.json palettes; all small-text usages switched to the AA variants; `--ink-2` bumped #7c7869 -> #868171 (4.58:1 worst case); hardcoded small-text colors fixed (.cert-modern_interpretation -> #b96e55, .rel-type.conf-disputed -> #c56559).
Verified mathematically (WCAG formula, worst-case bg #17171e): japanese #d7594c 4.60, mesopotamian #4587b5 4.57, norse/slavic 2-text #b96e55 4.61, egyptian 2-text #358e88 4.56, ink-2 4.58, disputed #c56559 4.57; all other accents already >=4.5. Dark-on-accent-text badge reuse also >=5.0.
Awaiting QA re-audit (contrast sweep) + rebuild to confirm on :3002.
