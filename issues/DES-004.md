## Description
The /graph edge-legend div (marriage ♥, Creation, Conflict, ...) has aria-hidden with no alternative. IA a11y targets require every edge type exposed via aria-label and the legend, and 'color is never the only signal'. With the legend hidden, color/dash is the only channel for screen readers.

## Acceptance Criteria
- [ ] Legend exposed to assistive tech (remove aria-hidden; real list semantics)
- [ ] Edge-category names included in edge path aria-labels
- [ ] axe audit of /graph passes for legend exposure

## Implementation Reference
Remove aria-hidden from GenealogyGraph.tsx:563 legend; add aria-labels to overlay edge paths.
