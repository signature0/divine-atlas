## Description
`/culture/nope` (any unknown culture id) returns **500 Internal Server Error**
instead of a 404.

## Root cause
`app/culture/[culture]/page.tsx` — `generateMetadata` calls `loadCulture(culture)`
unconditionally. For an unknown id, `loadJSON('nope/entities.json')` throws
before the component's `notFound()` guard ever runs, so the route crashes with
a 500 during metadata generation. (Deity/myth/artifact routes already 404
correctly — this is culture-route-specific.)

## Repro
`curl http://localhost:3002/culture/nope` → 500 "Internal Server Error".

## Impact
Low (unknown ids are rare), but a 500 on the public site signals broken infra;
should be a clean 404 like every other detail route.

## Proposed fix
In `generateMetadata`, validate the culture against `ALL_CULTURES` and call
`notFound()` (or guard the load) before touching `loadCulture`. Mirror the same
guard pattern the other detail routes use.

## Acceptance
`/culture/nope` → 404; all six valid culture pages unchanged (200).
