## Description
IA requires the persistent top bar to carry a search icon that opens the ⌘K command-palette overlay. The ⌘K listener exists (SearchOverlay.tsx) but no visible trigger (icon or chip) exists anywhere in the top bar, on desktop or mobile. Search is the fastest route to any of 159 entities / 44 myths / 175 artifacts.

## Acceptance Criteria
- [ ] Visible search trigger in TopNav (icon + 'Search ⌘K' label) that opens the SearchOverlay
- [ ] Keyboard path ⌘K still works; trigger is focusable and labeled
- [ ] Mobile top bar includes the search trigger per IA 'wordmark + search + menu'

## Implementation Reference
Lift overlay `open` state into a context or dispatch a CustomEvent from the TopNav chip.
