## Description
All 206 `/domain/[domain]` routes whose parameter contains a space, paren, or
aprophe return **404 in production** (`next start` via systemd divine-atlas),
even though their HTML files exist in `.next/server/app/domain/` and they are
listed in the prerender manifest. Single-word domains (114) serve fine.

## Repro (production :3002)
- `/domain/war` → **200**
- `/domain/the%20void` → **404** (file `the void.html` exists in build)
- `/domain/the%20dead` → **404**
- `/domain/chaos%20(the%20pre-creation%20state)` → **404**

## Impact
- The **homepage** links `/domain/the%20dead`, `/domain/the%20underworld`,
  `/domain/the%20earth` (visible "Where the gods overlap" section) → 3 broken
  links on the front page.
- 206/320 domain pages (64%) unreachable — the domain index is mostly dead.

## Likely root cause (verify)
Prerender manifest keys hold the RAW param (`/domain/the void` with a space),
but the static-file lookup path is derived from the encoded URL
(`the%20dead.html`) which never matches the on-disk filename
(`the dead.html`). Next.js App Router static serving does not decode
percent-encoding for the filesystem lookup.

## Proposed fix
Slugify the domain in the route param (e.g. `the-void`, `the-pre-creation-state`
in parens stripped), emit `encodeURIComponent(slug)` in links, and resolve
back to the raw domain string inside the page component. Keep `generateStaticParams`
returning the slugs. Verify with the full qa-sweep.mjs re-run: expect 320/320
domain routes → 200.

## Acceptance
- All 320 /domain/* routes return 200 in production.
- Homepage domain chips resolve (0 404s in qa-sweep).
- qa/evidence re-run attached.

## Fix (commit 3c48aed, 2026-09-13)
Per HANDOFF-003: the route param is now the domain SLUG, not the raw string.
1. New shared util `app/lib/domain.ts`: `domainSlug()` (lowercase, trim, runs of
   non-alphanumeric → `-`, drop edge `-`), `allDomains()` (stable sorted raw set),
   `domainFromSlug()` (exact raw resolution), `allDomainSlugs()`. Slug
   uniqueness verified 1:1 over all 320 raw domains (0 collisions) before shipping.
2. `app/domain/[domain]/page.tsx`: `generateStaticParams` returns slugs; the
   component resolves the exact raw domain from the slug (unknown slug →
   `notFound()`) and matches `e.domains.includes(raw)` exactly as before.
   Side fix: mixed-case raw domains (e.g. "Izumo") now resolve — the old
   lowercase-the-param matching silently 404'd them (the "114 single-word → 200"
   QA count included one such 404).
3. `app/page.tsx`: archetype chips emit `href=/domain/<slug>` (slugs are
   `[a-z0-9-]+`, so no percent-encoding needed).
4. `scripts/qa-sweep.mjs`: domain route list now built from slugs via the same
   inline slug function (kept in sync with the util; .mjs can't import TS)
   — required so the orchestrator re-sweep visits the routes the build serves.
