## Description
All /deity/[id] pages render document.scrollWidth=1002px on a 390px viewport (verified 159/159 ids). The mobile .profile-grid override (globals.css:106) uses plain `1fr`, whose implicit min size is auto; long unbreakable citation spans force the track to 1002px. 1440px layout is fine (minmax(0,1fr) 360px).

## Acceptance Criteria
- [ ] /deity/[id] pages show no horizontal scroll at 390px (document.scrollWidth == clientWidth) for all 159 deity ids
- [ ] QA mobile sweep re-run over all deity ids with evidence
- [ ] Visual regression baselines regenerated @390

## Implementation Reference
Fix verified live: `@media (max-width:1000px){ .profile-grid{ grid-template-columns: minmax(0,1fr); } }` measured 1002->390 on /deity/gre-zeus (scripts/critic-verify.mjs). Add min-width:0 to grid children as belt-and-braces.
